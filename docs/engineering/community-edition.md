# 커뮤니티 에디션 정책

갱신일: 2026-11-03

## 기능과 사용량

모든 구현된 데스크톱·CLI 기능을 무료로 제공한다. 프로젝트·대상·월간 스캔·리포트·AI 가이드의
과금 한도와 라이선스 활성화를 제거한다. HTML/Markdown/JSON/PDF/SARIF는 모두 사용 가능하다.
사용량 통계와 감사 로그는 진단·활동 확인용으로 유지하며 기능 접근에 사용하지 않는다.

AI는 사용자가 제공한 API 키로 명시적으로 요청할 때만 실행한다. 외부 제공자 비용은 사용자 부담이다.
네트워크·입력·대상 승인·리소스 제한은 유지한다. 로컬 동시 스캔 용량은 2이며 구독 등급과 무관하다.
프로젝트 개수 제한이 없어도 저장장치와 메모리의 물리적 한계가 없어지는 것은 아니다.

## 룰과 업데이트

`built-in`, `community`, `local`과 기존 `pro`, `team`, `enterprise` 채널 문자열을 허용한다.
기존 이름은 호환성용 레이블이며 유료 기능이나 조직 서버의 존재를 의미하지 않는다.
알 수 없는 채널은 거절한다. 스키마·SHA-256·선택적 Ed25519 서명·ZIP 경로·크기 검사를 유지한다.
CLI의 `--pro-active` 옵션은 제거한다. JSON `entitlement_allowed`는 호환성을 위해 남기되
지원되는 채널인지만 표시한다. 원격 manifest 자동 다운로드·적용은 제공하지 않는다.

## 저장소 호환성

기존 프로젝트·대상·스캔·발견 사항과 SQL 마이그레이션은 유지한다. 과거 `licenses` 테이블과
workspace의 `plan` 열은 이전 DB와의 호환성 때문에 초기 스키마에 남지만 런타임에서
기능 접근을 결정하는 데 사용하지 않는다. 활성화·비활성화 API와 UI는 제거한다.
진단 출력은 라이선스·온라인 계정 메타데이터 대신 `edition: community`를 기록한다.

공개 소스에 스키마와 저장 코드는 포함하지만 실제 SQLite 파일, 사용자 키, 진단·리포트 데이터는
포함하지 않는다. 공개 준비 도구는 사용자의 설치 앱 데이터나 Credential Manager를 삭제하지 않는다.

## 검증

- 높은 누적 사용량에서도 스캔 접근이 유지되고 동시 실행 용량은 적용되는지 검사한다.
- 모든 지원 채널을 활성화 없이 검사하고, 잘못된 서명·ZIP 경로·입력은 계속 거절한다.
- 기존 DB에서 생성·조회·업데이트·스캔 복구 테스트를 유지한다.
- 공개 패키지에 개인 설정·키·DB·내부 계획·Git 이력이 포함되지 않는지 검사한다.
