# 2026-11-03 무료 오픈소스 전환

## 결정

사용자의 지시에 따라 앱 유료화를 중단하고 전체 구현을 공개할 수 있는 커뮤니티 버전으로 준비한다.
공개 라이선스는 앞선 검토에서 추천한 Apache-2.0을 적용한다.
소스 공개의 실제 원격 생성·공개 전환은 준비 완료 후 별도로 수행한다.

## 영향

- UI·Rust 백엔드·CLI에서 과금 제한과 라이선스 활성화를 제거한다.
- 사용자 API 키 방식의 선택적 AI와 네트워크·입력·리소스 안전 제한은 유지한다.
- 기존 로컬 데이터와 마이그레이션 호환성을 보존한다.
- 공개 README는 한국어·영어로 제공한다.
- 사용자의 최종 지시에 따라 새 저장소에 공개한다. 검토한 소스 스냅샷만 첫 커밋으로 추가하고
  기존 저장소의 Git 이력·원격 설정·작성자 정보를 옮기지 않는다.
- 실제 키·DB·설정·내부 계획·작성자 이력·빌드 산출물을 공개본에서 제외한다.
- 소스 공개와 서명된 Windows 설치 파일 배포의 검증 기준을 분리한다.

과거 상용 플랜 문서보다 이 결정과 `docs/engineering/community-edition.md`가 우선한다.

기존 원격 이력 교체는 중단한다. 이미 만든 원본 백업과 이력 정리 후보는 비공개로 보관하고
새 저장소에 업로드하지 않는다. 기존 저장소의 공개 설정은 변경하지 않는다.
새 저장소의 대상 URL과 공개 작성자 식별자를 확인한 뒤 소스만 올린다.
